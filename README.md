📊 HR Analytics Dashboard – Excel Pivot Tables

📌 Project Overview

This project presents an interactive HR Analytics Dashboard developed using Microsoft Excel and Pivot Tables. It helps analyze employee data, understand workforce trends, and generate meaningful HR insights.

🎯 Project Objectives

- Analyze employee data.
- Understand workforce distribution.
- Identify important HR trends.
- Support data-driven HR decision-making.

🛠️ Tools & Technologies

- Microsoft Excel
- Excel Pivot Tables
- Data Analysis
- Data Visualization

📈 Dashboard Features

- Interactive HR data analysis.
- Employee data summaries.
- Workforce trend analysis.
- Visual representation of HR metrics.
